# IP 信誉参考指数与证据规则

更新：2026-09-19。本文记录当前实现，替代旧分析文档中关于最终展示与评分的设计建议；历史问题见 `ip-quality-review-124.126.3.108.md`。

## 指标边界

页面展示的是本站规则定义的参考指数，不是欺诈概率、平台通过率、账号安全分或“全网纯净度”。当前尚无可靠真实标注样本的校准结果。各来源可能共享上游数据；“有效来源数”表示可用证据覆盖，不表示统计独立性或准确率。

参考公式保留原有三维权重：

完整维度时：`S = round(min(0.45 × 信誉 + 0.35 × 匿名 + 0.20 × 用途, 上限))`

存在未知维度时：`S = round(min(Σ(已知维度 × 原权重) / Σ(已知维度原权重), 上限))`。未知项保持 null，不填零分或默认“干净”。至少取得信誉或匿名的有效读数才有质量分；只有地址、用途或官方公共服务登记不能凭空造分。

没有用主观新权重强行改变目标地址的分数。已移除注册日期加分与缺失维度的默认分数，按用户要求恢复部分数据下的估算，当前策略为 `available-evidence-v3`。供应商原始数值、方向和用途标签仍分别展示。分档换算及用途偏好是本站规则，不能称为所有供应商认可的统一尺度。

## 未知与证据覆盖

- 匿名字段分别保留 true、false、unknown。VPN 否不能推导 Proxy/Tor 否；Hosting 否也不能推导非匿名。
- Worker 只输出实际读到的 `flags`。旧版仅包含 `No` 的扁平结果不再作为阴性依据；旧版明确的正向标签仍保留。
- 同一来源存在不同的信誉读数时，显示“信誉读数冲突”并排除其信誉投票；不能由数组顺序决定选择哪个数值。其它明确的匿名、用途事实仍单独保留。
- 完整的 VPN/Proxy/Tor 阴性组，或供应商明确的合并匿名阴性，才可作为该来源的匿名阴性证据。任一正向匿名标签均保留；不会被另一个未知字段覆盖。
- 信誉、匿名、用途分别列出有效来源。部分匿名阴性字段仍展示，但不能代替一组完整匿名检测。
- 部分来源未返回、某个信誉指标缺失或冲突时，其它有效读数继续参与计算；总分显示“估算”，数据覆盖与质量高低分别表达，不再因一家不可用隐藏总分。
- 信誉在实际已返回的有效供应商间按原相对权重归一；IPv6 的 IPPure 仍明确不适用。不同来源覆盖的估算分可能发生变化，不能把来源丢失后的涨分理解为质量真实改善。
- 匿名维只采用明确正向命中或完整阴性组/明确合并阴性。部分阴性字段仍不算完整阴性，缺失不代表“未检出”。
- 维度本身未知时从综合公式中排除，已知维度保持原权重比例后归一。页面计算说明展示实际生效的权重；Tor、住宅代理、滥用等已有上限继续生效。
- 状态分为 `ready`（覆盖达到现行规则）、`provisional`（有分数但存在缺失/有限证据）、`unavailable`（没有任何可用信誉或匿名信号）。这不是统计置信度。
- 顶部展示数字、结论、简短解释及一组最关键的依据对照。例如本次 IP 显示住宅/教育/商业用途的三源对照；完整摘要、缺失来源、采样时间、官方链接和公式放入“查看依据”。
- `checkedAt` 是本次交叉来源读取时间，不是各家数据库更新时间；目前没有取得供应商数据库更新日期。

## 用途与匿名结论

- 住宅、移动、ISP、企业/教育等机构、数据中心和公共服务分别建模。
- 住宅与机构、住宅与移动、数据中心与其他用途冲突时，明确列出来源及用途分歧。Coffee 内部用途冲突也保留。
- 组织/ASN 归属不再额外充当另一家独立用途票。来源用途标签仍不能代替线路运营方或现场接入证据。
- VPN、Proxy、Tor、Relay、住宅代理和未分类型匿名命中共享同一份归一信号，供卡片、分类、摘要和评分使用。匿名/中继特征不等同于恶意行为。
- IP-API 的合并 proxy 旗标不能确认为某一种 VPN 技术。
- 注册国与定位国相同时直接陈述这个事实，不再据此证明“原生 IP”。
- 增加独立维护的官方公共 DNS 用途登记，目前仅含已核实的 8 个精确地址，不匹配 ASN 或整个网段。页面和复制报告展示运营方链接及核对日期；登记自核对起 180 天有效，过期或查询时间早于核对时不使用。归一化使用项目已有的严格 IP 解析。
- 官方登记只保持公共服务用途与相应用途分支，不增加信誉、匿名或供应商用途票数；匿名与滥用命中优先于公共服务标签。只有官方用途记录、没有信誉或匿名信号时不造分。

## 场景测量

平台星级描述当前浏览器访问公开端点的 HTTP 速度。总览按平台显示与查询 IP 一致、不同和未核验的出口数。不同出口保留本浏览器的速度结果，但不能作为查询 IP 的平台可用性证据。没有登录、对话、交易或播放成功的推论。

## 回归与后续校准

已建立第一批 10 条真实响应快照，其中 8 条有官方公共 DNS 用途标签，覆盖 3 个运营方。相同官方记录现在进入生产用途登记，因此报告将这 8 条改为“登记规则检查”，排除出独立准确率分母。可运行 `pnpm quality:evaluate` 离线复跑，查看 [试验结果](./ip-quality-calibration-results.md) 和 [采样与标签规则](./ip-quality-calibration.md)。修复前的结果冻结在 `scripts/ip-quality-data/baseline-coverage-v1.json`；不能把暂停评分记成零波动，也不能把登记查表一致性宣称为模型泛化能力。

回归用例覆盖部分字段缺失、旧版 No、机构用途冲突、只有信誉/用途而没有匿名数据、Proxy/Tor/Relay 命中、孤立 Tor 命中、信誉来源不足、外部来源缺失以及 RDAP 年龄不改变评分。场景测试覆盖平台级出口归属及 mismatch 不变成失败。

后续校准需另外准备有可信用途标签、采样时间与来源版本的真实 IP 数据集，区分住宅、企业/校园、机房和各类匿名出口；用独立验证集评估用途误判和风险指标，才能有依据调整权重。模拟回归样本不能充当真实用途标签，也不能用于宣称准确率。
