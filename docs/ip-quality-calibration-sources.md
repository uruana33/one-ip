# IP 质量校准标签：官方公共 DNS 样本

更新：2026-09-19（Asia/Taipei；下列抓取时间使用 UTC）。本文和 [`scripts/ip-quality-data/labels.json`](../scripts/ip-quality-data/labels.json) 记录第一批可公开验证的正向用途标签，供离线校准和回归场景使用。

## 样本范围

本批包含 8 个地址，来自 3 个相互独立的运营方：

| 运营方     | 地址                                         | 官方用途                | 地址族      |
| ---------- | -------------------------------------------- | ----------------------- | ----------- |
| Cloudflare | `1.1.1.1`, `1.0.0.1`, `2606:4700:4700::1111` | 标准公共 DNS 解析器     | IPv4 / IPv6 |
| Google     | `8.8.8.8`, `8.8.4.4`, `2001:4860:4860::8888` | Google Public DNS       | IPv4 / IPv6 |
| Quad9      | `9.9.9.9`, `149.112.112.112`                 | 推荐的递归公共 DNS 服务 | IPv4        |

每条记录都保存了官方 URL、抓取时间、简短证据摘录、`family` 和运营方 `group`。评估时应按 `group` 去重或分层抽样，避免同一运营方的多个 anycast 地址被当作 3 个独立运营方证据。

## 证据与边界

- 这些标签表达的是“官方文档明确提供公共 DNS 服务”的用途事实，`expectedKind` 为 `public-service`。
- 公共 DNS 是服务用途标签，不是住宅、企业、校园、机房或托管标签。
- 公共 DNS 地址可能是 anycast 或多地点服务端点；这里不推断具体接入线路、用户群体、风险水平或出口是否使用代理。
- 这些正向标签不能反推出“安全”“无代理”“非 VPN”“非 Tor”或其他匿名状态。
- 未收录 `124.126.3.108`、`74.120.253.118` 等待评估地址，因此不会把目标地址当作真值样本。
- 本批没有住宅、企业、校园、机房或 Tor 真值；不能据此宣称模型已经完成真实世界校准，也不应据此调整权重。
- 本批暂不纳入 Tor exit 列表或 AWS CIDR：Tor 标签需要按采样时间刷新，AWS 网段只能说明官方分配边界，不能把网段内任意单 IP 当作已分配实例真值。

<https://developers.cloudflare.com/1.1.1.1/ip-addresses/>

抓取时间：`2026-09-18T16:52:12Z`。标签文件中保留了 3 个地址；同一页还列出其他 Families 地址，本批没有将过滤服务混入标准公共 DNS 样本。

<https://developers.google.com/speed/public-dns/docs/using>

抓取时间：`2026-09-18T16:52:12Z`。标签文件选取前三个地址，保留 IPv4 主备和一个 IPv6 地址。

### Quad9

Quad9 官方服务地址页在推荐的递归 DNS 配置下列出 `9.9.9.9`、`149.112.112.112` 及 IPv6 地址：

抓取时间：`2026-09-18T16:52:12Z`。标签文件选取两个 IPv4 地址；Quad9 IPv6 地址仍可作为后续扩充样本，但本批已满足 IPv4/IPv6 混合和三家运营方覆盖。

## 使用建议

校准脚本可以验证三类行为：官方公共服务标签是否被识别为用途证据、同一 `group` 是否不会被错误计为多家独立来源、缺少标签时是否保留 unknown。此数据集适合做证据管线和回归校验，不足以估计住宅/机房误判率或风险分的准确率。
