## 已完成的行为验证

- 首页：同一冻结样本输出与地址详情一致的用途分歧、估算分和三源关键依据。国内失败时外部结果不换位；已有数据重取失败时保留并标“上次结果”；冲突证据不会因 cross 请求异常被空成功覆盖。
- AI：代理阴性需 VPN/Proxy/Tor 明确为否；地区标签仅说明定位；无 IP 的 disabled query 不无限加载；未配置 API 出口明确标未配置；样本覆盖、旧出口/延迟时间可见。线路属性卡片默认直接展示，移除“阵营领先”推断。
- Claude：改为客观环境观测与完成度，移除国家/账号风险总分及加分；WebRTC 不支持、失败、无候选和非公网候选均不等同“泄漏/未泄漏”。
- 状态：官方健康与端点响应为独立证据；HTTP 500/401 不等同官方正常；DeepSeek RSS 失败仍为未知；未知分母、重取失败、五分钟以上结果均不计为当前健康；详情组件和事件同样标旧。
- 网络：DNS 混合来源按原始来源计数拆分；DOM 实测同一解析器国内 3 次、海外 13 次，不再两边都 16 次。DNS/CDN 树根表示来源分类，HTTP 出口只做独立对照。所有解析器地址规范校验；WebRTC 同协议族比较。
- 查询：WHOIS 本地快照后台刷新，失败保留原快照及时间，vCard 名称优先；中文枚举映射保留 raw；单源位置不称多数一致；Ping 统计说明按节点平均值。

浏览器已验证正常页面与外部请求受阻、状态过期、部分未知等模拟场景。没有启动全球 Ping，也没有用模拟响应证明外部服务真实可用。

## 最终复核补充

- AI 全失败显示成功 `0/n`；无数据与未配置均有明确状态。无代理标记只就 VPN/Proxy/Tor 的完整阴性组作判断，不扩大成没有滥用或机器人信号。
- Claude 候选使用“公网 / 非公网 / 未知”，不把所有非公网地址误称为私网。未知 UA 的 Emoji 线索也保留未知。
- WHOIS 两类旧数据都已验证：本地 placeholder 失败，以及已有 live data 后 refetch 失败。错误结果不会再次保存为新读取时间。
- 位置分歧包含同名城市但地区/国家不同，坐标不跨冲突地区混合。
- DNS 双树节点、叶子点击均从对应切片读取；真实页面点击得到国内 3 次、海外 13 次。两个国内 HTTP 对照地址不会构造假的海外出口。
- 原审计排除项仍排除，没有把 Geo 读取失败误列成丢失已测出口 IP。

## 首页动画恢复

出口示意改为探针观测后，原有流动路径与光点随旧 SVG 一起被替换。现已恢复线路流动、路径光点、节点脉冲和卡片入场，移动端使用简化线路动画；属性与证据卡片直接展示。

- 动画表示探针观测，两个线路周期一致，不代表网络速度或代理生效。
- HTTP 探针状态与质量来源状态分开：质量来源失败保留旧结果提示，不停止本轮成功出口的动画；探针失败则静止，检测中显示等待动效。
- 页面不可见或示意图离开视口时暂停；遵循系统减少动态效果设置。
- 浏览器实测光点位置随时间变化；390px 下无横向溢出，隐藏的桌面动画关闭；桌面与移动端减少动态效果、离屏暂停/返回恢复均通过。
